Smart Machine Temperature Monitoring System Using Python

1. What It Does

This project is a Python-based machine temperature monitoring system designed to monitor the temperature of machines and detect abnormal temperature conditions.

The program collects five temperature readings, calculates the highest, lowest and average temperatures, and uses a three-colour traffic light indicator to show the machine's condition.

2. How to Run It

1. Install Python 3 or Pydroid 3 on Android.
2. Download or copy the Python source code.
3. Save the file as "temperature_monitor.py".
4. Open the file in your Python application.
5. Run the program and enter five temperature readings.

Command:

python temperature_monitor.py

4. My Own Twist

I added three special features to make my project different:

1. Three-Colour Traffic Light Indicator: Green indicates normal temperature, yellow indicates warning, and red indicates critical temperature.
2. Digital Temperature Gauge: Displays temperature readings using a visual bar.
3. Alarm Sound: Provides an alert when the machine reaches a critical temperature on supported systems.
